# GANg generated-node example

This folder describes one GANg-generated MOF-like descriptor-space graph node. No generated CIF is produced in this version because GANg operates in descriptor space. Structural decoding is future work.

The CIF file, if present in future versions, must be a nearest real QMOF analogue used for interpretation. It is not a generated structure and not a physically validated output of GANg.
